# Epidemic_Calculator
Um trabalho utilizando IA's Generativas para a realização de uma calculadora epidemica com o intuito de modular a dengue bem como sua taxa contaminação.

*Como usar*

pip install numpy scipy matplotlib
python dengue_model.py

*Prompts Usados*

"Quero que faça um código em linguagem Python. Esse código tem o objetivo de modelar a dengue e seu espalhamento como uma calculadora epidêmica.";
"depois de cada resultado, quero que limpe a tela após apertar Enter e seja redirecionado a escolha do modo de execução";
"Faça um artigo científico explicando o código bem como suas referências utilizadas, o artigo será feito em inglês."

*IA's utilizadas*

Claude code: Sonnet 4.6 adaptativo
